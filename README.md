# RDSMNet  
Enhancing Photogrammetric DSM Based on Multiscale and Domain-Invariant Semantic Feature Learning

This repository provides the **official implementation** of **RDSMNet**, a deep learning framework for refining photogrammetric Digital Surface Models (DSMs) using multiscale semantic features and domain-invariant learning strategies.

---
- **Environment Setup**:  
  The environment configuration refers to **`requirements.txt`**.

- **Usage Instructions**:  
  Please refer to this **`README.md`** for detailed usage instructions.
  
## 🚀 Quick Start

### Training
```bash
python train.py config_train_xx.json
```

### Testing
```bash
python test.py config_test_xx.json
```

## 📋 JSON Configuration File Structure
#### datasets (Multiple datasets supported, indexed by 0, 1, 2, ...)
```bash

    #inside every dataset
    
    name:"sd_dataset"  #name of dataset
    raster_gt:"/mnt/wxq/ResDepth/DATA/new/SD1/SD_GT_Clip2.tif"  #DSM Ground Truth
    raster_in:"/mnt/wxq/ResDepth/DATA/new/SD1/SD_raw_Clip2.tif"  #initial DSM input of the dataset（waiting for refinement）
    path_image_list:"/mnt/wxq/ResDepth/DATA/new/SD1/imagelist_notCF.txt" #orthophoto- remote sensing image after ortho-rectified（pay attention to the format）
    path_pairlist_training:"/mnt/wxq/ResDepth/DATA/new/SD1/pairlist_stereo_notCF.txt" #orthophoto- remote sensing image after ortho-rectified（pay attention to the format）
    path_pairlist_validation:"/mnt/wxq/ResDepth/DATA/new/SD1/pairlist_stereo_notCF.txt" #same as above
    area_type:"train+val"  #choose train+val mode, must in training
    allocation_strategy:"5-crossval_vertical" 
    test_stripe:2
    n_training_samples:6000 #training samples amount for every dsm file
    crossval_training:true #cross validation usually set as true
    mask_ground_truth:"/mnt/wxq/ResDepth/DATA/new/SD1/loss_mask_SD1.tif" #path of the loss mask，area set as 1 represents the building area, which means ROI, involved in the loss calculation. If there is no mask set, then all the area takes part in the loss calculation.
```

## ⏰ Notes 

**Orthorectified Images:** Remote sensing images corrected using the initial DSM.

⚠️ **Critical:** Must use the corresponding initial DSM (to be refined) for orthorectification. Otherwise, results are meaningless.

**Initial DSM:** Can be generated by any method (traditional stereo matching or deep learning approaches).
